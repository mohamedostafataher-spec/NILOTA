# Shapefiles and boundary data

Boundary datasets used by NILOTA for maps and geographic features.

| File | Contents | Source | License |
| --- | --- | --- | --- |
| `geoBoundaries-EGY-ADM1-all.zip` | Egypt ADM1 (27 governorates), shapefile + geojson + topojson, representative of 2017 | geoBoundaries / OpenStreetMap (Wambacher) | Open Data Commons Open Database License 1.0 (ODbL) |
| `geoBoundaries-EGY-ADM1.geojson` | Egypt ADM1 as GeoJSON (same dataset, unpacked) | geoBoundaries / OpenStreetMap (Wambacher) | ODbL 1.0 |
| `geoBoundaries-EGY-ADM2-all.zip` | Egypt ADM2 (365 marakiz and aqsam), shapefile + geojson + topojson, representative of 2020 | geoBoundaries / OCHA ROMENA-HDX + CAPMAS | Creative Commons Attribution 3.0 IGO (CC BY 3.0 IGO) |
| `ne_10m_admin_0_countries.zip` | Natural Earth 1:10m country boundaries | Natural Earth | Public domain |
